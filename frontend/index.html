About this prototype

This project is developing a regional forecasting workflow and a public interface for exploring its predictions.

  • Current stage: displaying Open-Meteo irradiance forecasts and cloud cover.
  • Planned additions: an interactive map, location-based time series, and forecast timestamps.
  • Research goals: incorporate satellite data, train forecasting models, and evaluate predictions against independent observations.

Research demonstration only. Forecasts are supplied by Open-Meteo, not a custom machine-learning model. Cloud categories use simple cloud-cover thresholds and are not official weather alerts. This project has not independently validated the forecasts.
