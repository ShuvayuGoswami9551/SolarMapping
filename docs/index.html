About this prototype

This project is developing a regional solar forecasting workflow and an accessible interface for exploring its predictions.

  • Current data: provider-supplied hourly irradiance forecasts and cloud cover from Open-Meteo.
  • Interface features: a sample-point map, synchronized forecast times, location-based charts, hourly tables, and CSV export.
  • Research evaluation: a separate Bondville, Illinois experiment compared archived predictions with ground observations. That experiment does not establish accuracy at the Maryville map locations.
  • Future research: additional atmospheric predictors, satellite observations, and independently evaluated custom machine-learning models.

Research demonstration only. Displayed predictions are supplied by Open-Meteo, not a custom machine-learning model. Cloud descriptions use simple cloud-cover thresholds; they are not satellite cloud classifications or official weather alerts.
